# CPU and Hardware Concurrency

## 1. Introduction

Performance engineering requires an understanding of the hardware on
which a program executes.

For concurrent and lock-free systems, CPU cores, logical processors,
CPU frequency, and hardware concurrency directly influence how
threads execute and how benchmark results should be interpreted.

---

## 2. CPU

CPU stands for Central Processing Unit.

The CPU executes instructions generated by a program. Modern CPUs
contain multiple processing cores, allowing multiple tasks to execute
concurrently.

For performance engineering, important CPU characteristics include:

- CPU model
- Number of physical cores
- Number of logical processors
- CPU frequency
- Cache hierarchy
- Hardware threading capabilities

---

## 3. Physical CPU Cores

A physical core is an independent execution unit within a CPU.

For example, a CPU with four physical cores can potentially execute
work on four cores in parallel.
