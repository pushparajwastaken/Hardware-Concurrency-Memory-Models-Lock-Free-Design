At -O0, GCC generated a relatively direct implementation of foo, including a stack frame and memory locations for intermediate variables. At -O2, GCC optimized the function to operate primarily on registers and reduced the computation to three arithmetic instructions. Furthermore, because main() calls foo(10,20) with compile-time constants, GCC evaluated the result as 242 during compilation and eliminated the function call. This demonstrates compile-time optimization and should not be confused with runtime out-of-order CPU execution.
