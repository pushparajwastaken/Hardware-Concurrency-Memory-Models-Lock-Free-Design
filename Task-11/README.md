# Performance Engineering

## Role

Member 11 – Performance Engineering

## Main Research Topic

Hardware Concurrency, Memory Models & Lock-Free Design

## Objective

The objective of this work is to establish a reliable and reproducible
performance benchmarking methodology for concurrent and lock-free systems.

## Responsibilities

- Define a common benchmarking methodology
- Standardize benchmark configuration
- Collect hardware and software environment information
- Define warm-up, iteration and repetition requirements
- Collect benchmark results from team members
- Analyze latency and throughput
- Calculate median and percentile measurements
- Identify suspicious or unreliable results
- Generate standardized performance graphs
- Prepare performance analysis for the final research report

## Key Metrics

- Latency
- Throughput
- P50
- P90
- P95
- P99
- CPU utilization
- CPU frequency
- Memory usage
- Temperature / thermal conditions

## Research Areas

- Hardware concurrency
- CPU affinity
- NUMA
- Cache behavior
- Cache coherence
- False sharing
- Lock-based synchronization
- Lock-free programming
- Atomic operations
- CAS
- Memory ordering

## Deliverables

- Benchmark methodology
- Standard benchmark template
- Environment metadata
- Benchmark results
- Performance graphs
- Performance analysis
