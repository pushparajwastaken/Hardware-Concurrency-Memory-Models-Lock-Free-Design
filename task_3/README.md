# Store Buffers & Memory Ordering in Modern Multi-Core Processors

## Overview
Research on store buffers, instruction reordering, memory visibility, and memory ordering in multi-core processors.

## Objectives
- Understand store buffers and memory fences.
- Analyze the Store Buffering litmus test.
- Compare relaxed and sequentially consistent atomics.
- Explore practical concurrency applications.
