The experiments demonstrated the difference between independent and dependent instructions. In the independent example, the computations a + b and c + d did not depend on each other, allowing a superscalar out-of-order CPU to potentially execute them in parallel using available execution resources. In the dependent example, each computation depended on the result of the previous one, creating a RAW (Read After Write) dependency that limits instruction-level parallelism. The compiler also optimized the dependent computation by eliminating intermediate variables and reducing the number of instructions. These experiments demonstrate that out-of-order execution can exploit independent work, but it cannot eliminate true data dependencies. They also show that compiler optimization and CPU-level out-of-order execution are separate mechanisms.
