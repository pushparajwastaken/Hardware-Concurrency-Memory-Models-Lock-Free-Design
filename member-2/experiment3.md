The branch experiment demonstrated the difference between compiler-generated control flow and CPU branch prediction. At -O0, GCC generated a conditional jump (jle) corresponding directly to the C++ if/else structure. At -O2, GCC optimized the code by computing both possible results and using a conditional move (cmovge) instead of a conditional branch. Therefore, the optimized version can avoid branch-prediction penalties for this decision. This demonstrates that compiler optimization can change the control-flow structure before execution, while branch prediction is a separate runtime CPU mechanism.
